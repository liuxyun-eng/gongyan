# 共研 v0.1.0 · AI 工作，交给团队复核

共研提供一个简单的交接入口：继续在 Codex 中完成工作，把对话复制为 Markdown，再和本机工作目录一起发布。伙伴在同一个工作区阅读过程、复制内容并下载成果。

这是首个早期预览版本，面向一起做科研、电子设计和课程项目的小团队。

## 本版能力

- 注册登录、创建工作区与邀请码加入。
- Codex Markdown 对话导入，代码、公式、表格和流程图展示。
- 工作目录上传，保留子目录与空文件，逐文件读回校验 SHA-256。
- 工作区成员访问控制与私有文件存储。
- 单段消息复制与权限控制的删除，作者右键删除整条共享快照。
- 完整源码、本机开发指南、腾讯云部署脚本与合成测试。

## 体验

[打开共研](https://gongyan-d6gqg5jl234d901e6-1503317224.ap-shanghai.app.tcloudbase.com/)，注册账号、建立工作区、邀请伙伴，再点击“分享 Markdown”。体验地址使用腾讯云测试域名，可能出现平台提示。

## 验证

14 项 Markdown 与对话处理单元测试通过，TypeScript 检查通过，腾讯云前端及后端构建通过。已用合成资料验证目录上传、下载散列、成员权限和删除行为；测试结果不构成生产级服务保证。

## 已知边界

当前提供手动发布的只读快照，不支持实时同步或多人编辑。每次最多 500 个文件、单文件 20 MB、目录总量 200 MB。历史分页、过期上传清理及跨页面恢复尚待完善。Markdown 还原取决于导出内容，无法保证与原客户端逐像素一致。

反馈请提交到 [Issues](https://github.com/liuxyun-eng/gongyan/issues)，附脱敏的最小示例。仓库仅包含程序、文档与合成测试，不包含用户上传的 Markdown、附件或凭证。
